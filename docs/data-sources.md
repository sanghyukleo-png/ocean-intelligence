### 인프라 제약 (전 지표 공통)
- **Vercel Hobby 플랜 cron은 하루 1회, ±59분 오차**. 시간당 이상 수집 표현식은 배포 실패. Pro는 분 단위 가능. ([Vercel 문서](https://vercel.com/docs/cron-jobs/usage-and-pricing), 2026-07-15 갱신본)
- 따라서 특보 10분·벙커 1~3시간 주기를 Hobby에서 돌리려면 **외부 스케줄러**가 필요하다. 후보: Supabase `pg_cron` + `pg_net`(저장소와 같은 곳), GitHub Actions schedule(최소 5분, 지연 잦음), Upstash QStash. 권장안은 6장.

## 7. 저장소 · 스케줄러 권장안 (확정 전)

- **Supabase(Postgres) 무료 티어**: 시계열 테이블 + 마지막 성공값 조회가 SQL로 단순. `pg_cron` + `pg_net`으로 `/api/ingest/[source]`를 주기 호출하면 Vercel Hobby의 1일 1회 제한을 우회할 수 있다(호출 엔드포인트는 비밀 토큰으로 보호). 무료 프로젝트 비활성 일시정지 정책·pg_net 사용 가능 여부는 계정 생성 후 확인.
- 대안: Vercel Pro 전환(분 단위 cron, 비용 발생) 또는 GitHub Actions schedule(무료, 지연 가능).
